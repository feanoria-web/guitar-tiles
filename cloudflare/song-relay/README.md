# Riffline Cloudflare Song Relay

Bu Worker, multiplayer odasındaki hostun şarkıyı R2'ye bir kez yüklemesini ve
odadaki diğer oyuncuların aynı dosyayı doğrudan R2'den indirmesini sağlar.
Firebase Realtime Database oda üyeliğinin doğrulanması için kullanılmaya devam
eder.

Kurulumun tamamı `docs/CLOUDFLARE_SONG_RELAY_TR.md` dosyasındadır.
